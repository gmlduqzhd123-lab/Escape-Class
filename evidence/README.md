# 최초 로컬 검증 기록

이 폴더는 GitHub 저장소 연결 전 구현 단계에서 생성한 로컬 증거입니다. `environment.json`의 Git 저장소 없음·배포 미실행은 그 시점의 환경입니다. `release-manifest.json` 역시 최초 로컬 산출물의 파일 해시이며 이후 문서 변경까지 포함한 현재 Git 트리의 해시 목록이 아닙니다.

핵심 로직 28개와 브라우저 검사 36개가 통과했습니다. 브라우저 검사는 설치된 Windows Edge를 사용했고, 공식 회차와 학교는 테스트 전용 정적 응답 fixture였습니다. 실제 학생·교사 승인, 물리 기기, 운영 학교 목록을 증명하지 않습니다.

원격 공개 앱은 `https://gmlduqzhd123-lab.github.io/Escape-Class/`이며, 저장소 연결 이후 공개 사이트에서 새 검증 기록을 별도로 생성합니다. 기존 증거를 원격 배포 증거로 바꾸어 표현하지 않습니다.
