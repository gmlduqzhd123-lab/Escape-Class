# 교실 탈출 구현 완료 보고

검증일: 2026년 10월 23일 (한국 시간)

이 문서는 **GitHub 저장소를 제공받기 전 최초 로컬 구현 단계의 검증 기록**입니다. 아래 커밋·푸시·배포 미실행과 AC29 미실행은 그 단계의 상태이며, 이후 연결한 저장소와 공개 앱 주소는 [README](../README.md)에 안내합니다. 원격 배포 단계는 이 기록과 별도로 확인합니다.

## 결과

「교실 탈출」 첫 에피소드 「사라진 우정 열쇠」를 실행 가능한 정적 웹앱으로 구현했습니다. 필수 화면 8개, 조사 물건 12개, P1~P5, B1~B4, 최종 조합·열쇠·출구, 저장·이어하기, 성찰·인쇄, 학교·회차·공식 순위·로컬 집계를 포함합니다.

현재 폴더에는 기존 소스·Git 저장소·원격 주소가 없었고 적용할 `AGENTS.md`도 발견되지 않았습니다. 새 프로젝트를 만들었으며 사용자 원본 지시문은 [SPEC.md](SPEC.md)에 보관했습니다. 실제 학교·회차 정보가 없어 운영용 데이터는 빈 학교 목록, 연습 회차, 빈 순위로 유지했습니다.

## 전체 플레이와 화면 확인

PC에서는 학교 없이 시작해 단서 수집 → 공용 렌즈 → P1~P5 → 보너스 4개 → 지도 조합 → 화분 받침 조사 → 가방의 열쇠 선택 → 출구 사용 → 100점 확정 → 성찰·인쇄 화면까지 진행했습니다.

360px 화면에서는 테스트 전용 등록 학교·공식 회차를 사용해 다시 전체 게임을 진행하고 B1·B3을 포함한 90점 결과 파일을 실제 다운로드했습니다. 다운로드 구조는 허용 필드와 정확히 일치했습니다. 결과 파일의 회차를 바꾸지 않았으며, 현재 설정이 새 회차로 바뀌면 기존 기록의 공식 내보내기가 차단됐습니다.

필수 게임 조작은 포커스와 Enter로 실행했으며 드래그를 사용하지 않았습니다. Escape 패널 닫기와 조사 대상으로 포커스 복귀, 본문 바로가기의 해시 경로 유지, 모바일 조작 대상의 44px 크기를 확인했습니다.

아래 화면을 실제 렌더링한 PNG가 `evidence/`에 있습니다.

- 시작 화면: PC·태블릿·360px
- 게시판 P1, 공 경로 P3, 도움 지도 P5: PC
- 투명 렌즈 P2, 연결망 P4, 마지막 조합 지도, 공식 결과: 360px
- 수업 안내: 768px
- 결과 화면과 인쇄 미디어: PC

학교·활동 설정과 이야기 화면은 두 전체 플레이에서 실제 거쳤습니다. 공식 순위의 빈 상태와 집계 화면은 자동 브라우저 검사로 확인했습니다.

## 실행·빌드·배포 상태

## 남은 제한

- 실제 운영 학교 등록과 공식 회차 개설은 운영자가 실제 정보로 해야 합니다.
- 학교 소속과 실제 플레이 여부는 정적 앱과 JSON 형식 검사만으로 인증하지 않습니다. 운영자가 대표 모둠의 결과를 확인합니다.
- 실제 학교 기기·학생·교사의 사용성 및 20~25분 플레이 시간은 별도 수업 검증이 필요합니다.
- 온라인 최초 접속 기준이며, 서비스 워커와 완전한 오프라인 최초 시작은 포함하지 않았습니다.
- Safari·Firefox와 실제 터치 기기 검증은 미실행입니다. 이번 브라우저 근거는 Windows의 설치된 Microsoft Edge입니다.
- 지난 회차의 마지막 게시본 조회는 지원하지만, 여러 과거 회차를 고르는 보관함 UI는 없습니다.

운영 절차는 [OPERATIONS.md](OPERATIONS.md), 수업 구성은 [TEACHER.md](TEACHER.md), 자산 권한은 [ASSETS.md](ASSETS.md)에 정리했습니다.
