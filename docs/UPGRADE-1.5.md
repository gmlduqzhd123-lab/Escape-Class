# 고도화 10가지 · 1.5.0

기존 색상·글꼴·방탈출의 기본 조작을 유지합니다. 학생의 필수 진행에는 기존 목표와 네 가지 탐색 도구를 사용하고, 연습과 교사용 도구는 선택 화면에 둡니다.

| 순서 | 기능 | 여는 곳 / 실제 동작 |
| --- | --- | --- |
| 1 | 30초 직접 조작 연습 | 이야기 안내 또는 메뉴→연습·교사용 도구. 상자 조사→장소 이동→가방에서 열쇠 선택→사용을 직접 눌러 봅니다. 본 게임의 도구·점수는 바뀌지 않고 연습 중 활동 시간은 멈춥니다. |
| 2 | 탐색 지도 | 이동→한눈에 보는 탐색 지도. 현재 위치, 다음 물건, 살펴본 곳을 지도와 번호에 표시합니다. 아래의 큰 물건 이름을 눌러 실제 장치로 이동합니다. |
| 3 | 오답 원인별 도움 | 기존 힌트에 지금 확인할 부분을 추가합니다. 직접 발언 미발견·추측 메모·렌즈 미사용/방향·미방문 친구·사진/도움 연결·부재중 교사·마지막 조각을 구분합니다. |
| 4 | 해결 이유 한 줄 | 조각 보상 화면의 ‘함께 알아낸 점’. 다음 장치로 가는 기존 버튼과 함께 짧게 읽습니다. |
| 5 | 선택형 대화 | 쪽지 장치의 ‘친구에게 말 걸기’ 또는 메뉴 선택 도구. 세 표현에 서로 다른 친구의 반응이 나옵니다. 반응은 정답·오답이나 학생 평가로 점수화하지 않습니다. |
| 6 | EP.03 사라진 응원 깃발 | 새 게임 수업 설정→체육관. 코트·골대·벤치·깃발 받침, 차례를 묻는 단서, 다른 렌즈 숫자, 모두의 이어달리기, 네 친구가 한 번씩 두 팀에 참여하는 새 계획 퍼즐과 도움 지도를 제공합니다. 공통 조작과 점수 엔진을 공유합니다. |
| 7 | 반복 변형 연습 | 수업 설정→다시 해도 다른 암호·카드. 새 게임의 숫자와 카드 배치를 바꾸며, 바로 전 숫자 변형은 다시 고르지 않습니다. 진행 도중 카드를 고르면 나머지 카드의 상대 순서는 유지합니다. 이어하기에서는 같은 변형을 복원합니다. |
| 8 | 교사용 진행 확인 | 수업 안내 또는 메뉴의 선택 도구. 해당 기기의 현재 물건·완료/남은 단계·추가 도움 단계·조합/열쇠/탈출 상태와 지도할 부분을 확인합니다. 기기 간 수집은 하지 않습니다. |
| 9 | 수업 전 오프라인 준비 | 수업 안내→필수 파일 준비·확인. 빌드의 글꼴·그림·정적 데이터·3D 지연 파일을 해시와 크기로 확인해 같은 배포 경로의 캐시에 준비합니다. 준비 뒤 새로고침과 다른 에피소드 최초 진입도 지원합니다. |
| 10 | 수업 이야기 편집 | 수업 안내→수업 이야기 편집·파일 불러오기. 바탕 에피소드, 제목, 시작 이야기, 가상 친구의 직접 대사, 여섯 도움 문장을 편집·JSON 다운로드·불러오기하고 새 게임에 적용합니다. |

## 교사용 파일

- 제목 40자, 시작 이야기 300자, 대사 160자, 도움 문장 각각 180자, 전체 파일 16KB 이하입니다. 파일 형식·에피소드·허용 필드를 검사하며 실패하면 기존 편집 내용을 유지합니다.
- 입력한 글은 화면과 인쇄 카드에서 HTML로 실행하지 않습니다. 외부 파일 주소나 코드 실행 필드는 없습니다.
- 기호 연결과 장치 정답 규칙은 유지합니다. 직접 대사는 가상 친구의 요청이 드러나도록 씁니다. 학생 이름·연락처·실제 피해 경험을 작성하지 않습니다.
- 변형·체육관·도서관·교사 편집·차근차근·협동 설정은 연습 활동입니다. 새 게임 시작 시 공식 회차를 붙이지 않으며, 기존 공식 결과 검증·집계 형식은 유지합니다.
- 기존 진행 저장 키와 본 진행 형식을 유지합니다. 새로운 수업 정보는 기존 경험 sidecar에 추가하며 구형 기록에는 기본값을 보충합니다.

## 오프라인 범위

첫 준비에는 인터넷 연결이 필요합니다. 준비 완료는 이 브라우저의 파일 캐시에 대한 확인입니다. 시크릿 모드·저장 공간 정리·앱 재설치 뒤에는 다시 준비합니다. 새 배포를 온라인으로 열면 새 파일 준비를 시도하며, ‘준비·확인’ 버튼으로 결과를 확인할 수 있습니다. 다른 앱의 캐시는 지우지 않고 이 배포 경로의 최근 세 캐시를 유지합니다.

## 검증 기록

- 단위·회귀 검사 101개, TypeScript/Pages 경로 빌드 통과.
- 전체 빌드 2,231,899바이트, JS/CSS gzip 228,378바이트로 기존 4MB/400KB 예산 이내입니다. Pages 워크플로에도 오프라인 검사와 용량 검사를 추가했습니다.
- 실제 빌드된 서비스 워커 검사 7항목 통과: 전체 파일 준비·준비 완료 조건·지연 파일과 글꼴/데이터의 연결 실패 복구·새 URL 탐색·오프라인 재확인·손상 파일의 원자적 실패·다른 출처 미개입. 현재 필수 파일 25개.
- 568×320에서 조작 연습 네 단계, 공간 지도 조사, 직접 발언 미발견/잘못된 숫자의 맞춤 도움, 분기 대화, 해설, 교사용 진행 확인을 직접 조작했습니다.
- 변형 체육관: 협동 암호 한 자리 저장/새로고침/이어하기, 변형 렌즈, 오답 팀의 빠진 친구 안내, 새 팀 퍼즐을 거쳐 필수 다섯 퍼즐·조합판·깃발 받침의 열쇠·80점 탈출 완료.

- 배포 빌드를 새 로컬 출처에서 준비한 뒤 **테스트 서버를 종료하고 HTTP 연결 실패를 별도로 확인**했습니다. 브라우저를 새로고침해 아직 연 적 없는 3D 체육관 파일을 캐시에서 불러왔고, 대화 중간 저장·새로고침·이어하기를 포함하여 80점 탈출했습니다. 연습 전후 활동 시간은 01:45로 유지됐고 해당 브라우저 오류 로그는 없었습니다.

실기기 터치·모바일 주소창·노치·모바일 운영체제 전체화면 검증은 사용자 요청대로 제외합니다. 공개 Pages의 워크플로·HTTP 해시·플레이 결과는 별도 증거 폴더에 남깁니다.
