# 교사용 40분 수업 안내

대상은 초등학교 3~6학년이며, 모둠마다 태블릿 또는 PC 한 대를 사용합니다. 배포된 사이트에 온라인으로 처음 접속합니다. 학생 가입·로그인과 개인정보 입력은 없습니다. 학교가 등록되어 있지 않아도 학교 없이 체험으로 전체 게임을 진행할 수 있습니다.

| 시간           | 활동                                        | 교사의 안내                                                             |
| -------------- | ------------------------------------------- | ----------------------------------------------------------------------- |
| 도입 5분       | 친구를 존중하는 행동과 가상 교실 이야기     | 실제 문을 잠그지 않으며, 원하면 언제든 쉬어도 된다고 안내합니다.        |
| 게임 25분      | 조사, 단서 읽기, 이유 설명, 배치·회전·사용  | 각 퍼즐마다 역할을 바꾸고 모두가 선택 이유를 말할 기회를 줍니다.        |
| 되돌아보기 5분 | 실천 문장 선택, 가상 상황에서의 선택 나누기 | 실제 피해 경험, 실제 친구 관계, 사과·용서·친해지기를 요구하지 않습니다. |
| 정리 5분       | 다음에 해 볼 작은 실천, 활동 기록 정리      | 필요하면 결과 인쇄 또는 이 앱의 활동만 지웁니다.                        |

## 모둠 역할 카드

- **관찰하기**: 물건과 기호를 찾아 모둠에 알려요.
- **단서 읽기**: 단서의 문장과 허락 안내를 천천히 읽어요.
- **이유 설명하기**: 선택한 까닭을 말하고 다른 친구의 생각도 들어요.
- **기기 조작하기**: 모둠에서 정한 선택을 버튼으로 조작해요.

이름을 역할과 연결하거나 기록하지 않습니다. 역할은 퍼즐마다 바꿀 수 있습니다. 기기 조작 담당만 혼자 해결하지 않도록 돕습니다.

## 힌트와 활동 시간

현재 살펴보는 장치와 추가 단서에 위치, 원리, 실제 해결 방법의 세 단계 힌트가 있습니다. 힌트를 사용해도 감점하지 않습니다. 막히면 먼저 친구가 읽은 단서를 다시 들어 보고 필요한 단계만 확인하게 합니다.

교실의 물건을 눌러 확대하고, 아래 아이템 칸의 도구를 선택한 뒤 사용할 대상을 누릅니다. 메모·조각을 누르면 다음 빈칸에 놓이고, 놓인 것을 누르면 뺍니다. 조각은 자동으로 반듯하게 맞춰지며 렌즈는 명시된 회전 버튼으로 돌립니다. 공 퍼즐은 공 옆의 칸을 이어 길을 만듭니다. 장치가 맞으면 조각과 다음 단서가 나타나므로 별도의 정답 확인 버튼을 찾을 필요가 없습니다. 물건 목록은 아래 메뉴에서 열 수 있습니다. 긴 장치는 페이지를 위아래로 움직여 살펴봅니다. 도움 요청은 한 단계씩 대화하며 편한 방법을 고릅니다. 추가 단서를 다 풀지 않아도 탈출은 성공입니다.

활동 시간은 현재 기기에서 실제 플레이한 시간이며 점수·동점 순위에 영향을 주지 않습니다. 안내·일시정지·탭 비활성화·결과 화면에서는 멈추며 강제 실패가 없습니다. 목표 시간보다 대화를 통한 해결을 우선합니다.

## 퍼즐에서 연습하는 행동

| 퍼즐        | 행동                                                       |
| ----------- | ---------------------------------------------------------- |
| P1 듣기     | 다른 친구의 추측과 당사자의 직접 발언을 구분해요.          |
| P2 존중     | 물건을 쓰기 전 허락을 확인하고 다른 공용 대안을 찾아요.    |
| P3 함께하기 | 참여하고 싶은 네 친구에게 공이 모두 닿도록 계획해요.       |
| P4 배려     | 사진 전달을 멈추고 도움 요청은 어른에게 이어지게 해요.     |
| P5 도움     | 어른이 부재할 때 다른 도움 경로를 찾고 요청 문장을 말해요. |

P4의 전달 차단이 이미 전달된 사진을 자동 삭제하는 것은 아니라는 점을 확인합니다. 도움 요청 활동은 가상 상황이며, 교사는 학교에서 실제 도움을 요청할 수 있는 경로를 따로 안내합니다.

## 성찰 문장

- 친구의 이야기를 직접 들어 볼래요.
- 물건을 쓰기 전에 물어볼래요.
- 함께하고 싶은 친구에게 기회를 나눌래요.
- 사진을 보내기 전에 확인할래요.
- 도움이 필요하면 어른에게 말할래요.

선택은 결과 화면에서만 사용하며 공개 순위·공식 결과 파일·개인 평가에 포함하지 않습니다. 게임 점수는 퍼즐 해결 기록입니다. 학생 인성이나 학교폭력 발생 수준을 나타내지 않습니다.

## 저장과 공식 도전

진행과 설정은 해당 기기·브라우저에만 저장되고 다른 기기에 자동 동기화되지 않습니다. 새로고침 후 이어하기는 일시정지 상태입니다. 저장을 사용할 수 없어도 현재 게임은 계속할 수 있지만 창을 닫으면 진행을 잃을 수 있습니다.

공식 도전 전 학교 대표 모둠을 정하고 그 모둠의 완료 결과 한 건을 제출합니다. 학교 선택은 소속 인증이 아니며 운영자가 확인한 학교별 한 건만 순위에 반영합니다. 자세한 절차는 [운영 안내](OPERATIONS.md)를 따릅니다.

앱은 이름·개인 닉네임·학년반·번호·연락처·사진·음성·실제 피해 경험을 입력받거나 전송하지 않으며, 카메라·마이크·위치·연락처 권한을 요청하지 않습니다. 호스팅 제공자는 자체 정책에 따른 접속 기록을 남길 수 있습니다.
