# 1.3 입체 교실 탐색과 전체화면

게임 시작 버튼에서 전체화면을 요청합니다. 브라우저가 지원하지 않거나 요청을 거절하면 브라우저 안에서 화면을 채웁니다. `화면 줄이기`와 `전체화면` 버튼으로 전환할 수 있습니다. 실제 전체화면의 Esc 동작은 브라우저에 맡깁니다.

## 학생의 조작

- 좌우 보기 버튼 또는 화면 밀기로 교실을 둘러봅니다.
- 바닥 이동 표시나 장소 버튼으로 통로를 따라 이동합니다.
- 물건 또는 물건 이름을 누르면 가까이 이동해 장치를 엽니다.
- 장치에서 `교실로`를 누르면 같은 자리와 시선으로 돌아옵니다.
- 위쪽 목표와 물건 목록으로 필요한 물건에 바로 접근할 수도 있습니다.
- `그림으로 보기`는 같은 진행 상태의 2D 교실을 엽니다. 3D 초기화에 실패해도 이 방식으로 이어집니다.
- 움직임 줄이기를 켜면 카메라 이동을 즉시 전환합니다.

## 구현 경계

Three.js 장면에는 교실의 열두 물건을 기존 물건 ID로 연결합니다. 벽, 가구, 바닥과 물건은 실제 입체 지오메트리입니다. 기존 크림색·초록색·나무색과 한글 글꼴, 동물 그림, 퍼즐 패널을 사용합니다. 카메라 탐색 자체는 점수나 단서를 변경하지 않으며, 물건을 조사할 때 기존 게임 엔진을 호출합니다.

영속적인 `#app`을 전체화면 대상으로 사용하고, 3D 호스트는 화면 갱신 중 보존합니다. 모달, 장치 화면, 일시정지, 숨긴 탭에서는 3D 조작과 애니메이션을 멈춥니다. 새 게임과 기록 삭제에서 장면 자원을 정리합니다. 카메라와 표시 모드는 기존 저장 스키마에 추가하지 않아 이전 활동 기록과 호환됩니다. 새로고침 후에는 교실 가운데에서 이어갑니다.

도움 지도 안의 복도·교무실·상담실은 기존 교육 퍼즐입니다. 3D 이동 공간은 교실입니다. 정적 Pages 배포이며 학생 계정·운영 DB를 추가하지 않습니다.

## 확인 기준

기존 단위 검사에 전체화면 지원/거절/해제/재진입/늦은 완료 관련 검사를 추가했습니다. 실제 UI 검증은 시작, 이동, 회전, 물건 조사, 화면 모드 전환, 저장 후 이어하기, 필수 다섯 퍼즐과 선택 네 퍼즐, 최종 탈출까지 수행합니다. 기기 화면 크기를 바꾼 검증은 실물 학교 기기나 실제 초등학생 사용성 시험과 구분합니다.
