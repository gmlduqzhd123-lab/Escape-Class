# 1.3 입체 교실 탐색과 전체화면

게임 시작 버튼에서 전체화면을 요청합니다. 브라우저가 지원하지 않거나 요청을 거절하면 브라우저 안에서 화면을 채웁니다. `화면 줄이기`와 `전체화면` 버튼으로 전환할 수 있습니다. 실제 전체화면의 Esc 동작은 브라우저에 맡깁니다.

## 학생의 조작

- 좌우 보기 버튼 또는 화면 밀기로 교실을 둘러봅니다.
- 바닥 이동 표시나 장소 버튼으로 통로를 따라 이동합니다.
- 물건 또는 물건 이름을 누르면 가까이 이동해 장치를 엽니다.
- 장치에서 `교실로`를 누르면 같은 자리와 시선으로 돌아옵니다.
- 위쪽 목표와 물건 목록으로 필요한 물건에 바로 접근할 수도 있습니다.
- `그림으로 보기`는 같은 진행 상태의 2D 교실을 엽니다. 3D 초기화에 실패해도 이 방식으로 이어집니다.
- 움직임 줄이기를 켜면 카메라 이동을 즉시 전환합니다.

## 1.3.1 이동과 선택 개선

- 현재 목표 물건의 이름표에 `다음`을 표시하고, 다른 이름표와 겹치면 먼저 보여 줍니다. 위쪽 목표에는 실제 목적지의 `살펴보기` 버튼을 함께 표시합니다.
- 발자국에 `가운데 통로 가기`처럼 도착할 곳을 적었습니다. 물건 목록도 다음 물건부터 보여 주고, 이미 조사한 물건은 다시 보기로 구분합니다.
- 목적지 버튼으로 이동했을 때 같은 장소에 현재 목표 물건이 있으면 그 물건을 바라봅니다. 예를 들어 공 퍼즐 차례의 `교실 뒤편으로`는 바닥 놀이판을 향합니다. 이동만으로 퍼즐을 조사하거나 해결하지 않습니다.
- 이름표 위에서도 화면을 밀어 둘러볼 수 있습니다. 드래그를 마쳤을 때 물건을 잘못 선택하지 않으며, 이동 중 설정이나 단서 노트를 열면 마지막 통로 위치에서 멈춥니다.
- 선택한 도구에는 그림 책상 또는 출구처럼 사용할 곳을 적었습니다.

## 구현 경계

### 1.3.2 휴대폰 가로 화면과 터치

세로 휴대폰에서 게임에 들어가면 가로 회전을 안내합니다. 가로로 돌리면 안내가 자동으로 닫힙니다. 회전 잠금이 필요한 환경은 `세로로 계속하기`로 진행할 수 있습니다. 안내 중에는 활동 시간과 교실 조작을 멈춥니다.

높이가 짧은 가로 화면에서는 교실 옆에 목적지 버튼을 배치하고, 아래에 도구와 메뉴를 한 줄로 표시합니다. 이름표와 발자국은 보기 버튼에 가려지지 않는 영역에 표시합니다. 퍼즐 화면은 세로로 스크롤할 수 있으며 하단 도구가 장치를 가리지 않습니다.

태블릿과 휴대폰의 주요 보기 버튼은 16px, 물건 이름은 15px, 이동 장소는 15px로 표시합니다. 일반 터치 영역은 최소 48px, 공간이 짧은 가로 화면의 보조 조작은 최소 44px입니다. 터치의 작은 흔들림은 탭으로 허용하고 세로 스크롤·두 손가락·취소된 드래그·길게 누르기를 조사로 처리하지 않습니다. 3D 교실 안에서 두 손가락을 벌리거나 오므리면 카메라가 1~2배로 확대·축소됩니다. PC에서는 마우스 휠, 두 손가락 조작이 어려우면 오른쪽의 ＋/－ 버튼을 씁니다. 다른 장소로 이동하거나 물건을 살펴보러 가면 원래 크기로 돌아갑니다. 3D 교실 밖의 화면은 브라우저 확대 제스처를 그대로 허용합니다.

터치 이벤트 로직은 `src/scene/gestures.ts`에서 분리해 취소·캡처 전환·다음 탭 복구 등을 검사합니다. 브라우저 화면 크기 검증과 실제 휴대폰 손가락 조작 검증은 구분해서 기록합니다.

Three.js 장면에는 교실의 열두 물건을 기존 물건 ID로 연결합니다. 벽, 가구, 바닥과 물건은 실제 입체 지오메트리입니다. 기존 크림색·초록색·나무색과 한글 글꼴, 동물 그림, 퍼즐 패널을 사용합니다. 카메라 탐색 자체는 점수나 단서를 변경하지 않으며, 물건을 조사할 때 기존 게임 엔진을 호출합니다.

영속적인 `#app`을 전체화면 대상으로 사용하고, 3D 호스트는 화면 갱신 중 보존합니다. 모달, 장치 화면, 일시정지, 숨긴 탭에서는 3D 조작과 애니메이션을 멈춥니다. 새 게임과 기록 삭제에서 장면 자원을 정리합니다. 카메라와 표시 모드는 기존 저장 스키마에 추가하지 않아 이전 활동 기록과 호환됩니다. 새로고침 후에는 교실 가운데에서 이어갑니다. 게임을 새로 열 때마다 입체 모드로 시작하며, 처음 누르는 "게임 시작" 또는 이어하기 후의 "일시정지 풀기"에서 전체화면으로 바뀝니다(브라우저는 화면을 누르기 전에는 전체화면을 허용하지 않습니다). 그 뒤 플레이 중에 직접 전체화면을 나가면 다시 강제로 켜지 않습니다.

도움 지도 안의 복도·교무실·상담실은 기존 교육 퍼즐입니다. 3D 이동 공간은 교실입니다. 정적 Pages 배포이며 학생 계정·운영 DB를 추가하지 않습니다.

## 확인 기준

기존 단위 검사에 전체화면 지원/거절/해제/재진입/늦은 완료 관련 검사를 추가했습니다. 실제 UI 검증은 시작, 이동, 회전, 물건 조사, 화면 모드 전환, 저장 후 이어하기, 필수 다섯 퍼즐과 선택 네 퍼즐, 최종 탈출까지 수행합니다. 기기 화면 크기를 바꾼 검증은 실물 학교 기기나 실제 초등학생 사용성 시험과 구분합니다.
