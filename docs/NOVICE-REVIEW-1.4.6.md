# 초등학생 관점 사용성 재검토 1.4.6

## 범위

공개 1.4.5를 실제 UI 조작으로 처음부터 80점 탈출까지 진행한 뒤, 초등학생이 다음 행동을 찾기 어렵다고 판단한 고도화 기능을 다듬었다. 실제 학생 관찰이나 실기기 시험 결과가 아닌 개발자의 사용성 점검이다. 색상·글꼴·3D 공간·게임 규칙·점수·저장 형식은 유지한다.

## 발견과 수정

| 발견                                                    | 수정                                                                                          |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 시작 화면에 학년·시간·협동·테마 선택이 모두 노출        | 현재 구성 요약은 보이고 세부 수업 설정은 접어서 필요할 때만 열기                              |
| 협동 카드 1·2 번호가 역할 교대 후 친구 번호와 혼동 가능 | 실제 배정된 ‘2번 친구 · 관찰 단서’ 등으로 표시, 도입에서 1~4번 자리 안내                      |
| 협동 카드 4개·숫자판·인쇄가 동시에 나타남               | 기호 순서 → 숫자 사전 → 암호의 3단계. 읽을 단서를 하나씩 표시하고 두 단서를 본 뒤 숫자판 제공 |
| 암호 단계에서 단서를 다시 보려면 어디로 갈지 불명확     | ‘단서 다시 보기’ 제공. 진행 복원 시 읽은 단서·부분 암호 유지                                  |
| 협동 도구함이 막혔는데 렌즈 퍼즐 힌트가 표시            | ‘도구함 힌트’에서 두 단서를 차례로 읽는 화면으로 직접 연결                                    |
| 단서 노트 위에 역할·인쇄 도구가 길게 배치               | 찾은 단서를 먼저 표시하고 역할 도구를 선택 항목으로 접기                                      |
| 장치 연출 버튼이 필수 행동과 비슷한 비중                | ‘장치 움직여 보기 · 선택’으로 접되 기존 연출은 유지                                           |
| 결과에서 개인 실천과 모둠 실천을 연달아 선택            | 모둠 약속을 먼저 표시하고 개인 되돌아보기는 선택 항목으로 접기                                |
| 선택 버튼으로 재렌더하면 펼친 설정이 닫힐 수 있음       | 같은 화면의 펼침 상태를 유지. 새로고침 시 기본 접힘으로 복원                                  |

## 검증

87개 자동 검사에는 실제 역할 교대 번호, 단서 확인 전 숫자판 차단, 복원한 암호 입력, 해금 후 설명 카드 접근, 협동 힌트와 기존 렌즈 힌트 분기, 수업 설정 기본 접힘을 포함했다. TypeScript 및 프로덕션 빌드와 브라우저 실제 클릭으로 다시 확인했다.

로컬에서는 교실 스스로·25분·협동으로 필수 5개 퍼즐 → 지도 조합 → 화분 → 열쇠 → 80점 탈출을 확인했다. 중간에 암호 한 자리 입력 후 새로고침·일시정지·계속하기, 다시 단서 보기, 선택 카드·노트·성찰의 펼침 상태를 확인했다. 공개 배포·도서관 경로·작은 가로 화면 확인 결과는 워크스페이스 Escape-Class-novice-review의 검증보고서와 JSON을 참고한다.

실기기 손가락 조작·실물 인쇄·학생 이해도 평가는 제외했다. 기존 체험·공식 결과 판정은 변경하지 않았다.
