# 이동·물건 목록·단서 노트 가로 화면 개선 1.4.10

## 확인 및 변경

- 배포판에서 단서 카드의 연결 기호 설명이 13px인 것을 확인했습니다. 스마트폰 가로 화면에서 16px로 키우고 줄 단위로 표시해 줄바꿈할 수 있게 했습니다.
- 카드 제목은 실제 제목 요소로 구분하고 가로 화면에서는 18px로 표시합니다. 조사한 물건 설명도 18px로 맞추고 줄 간격과 항목 사이 여백을 넓혔습니다.
- 물건 목록 이름은 18px, 버튼은 높이 64px 이상으로 조정했습니다. 긴 이름도 두 열의 버튼 안에서 줄바꿈합니다. ‘다음’, ‘살펴봄’, ‘다시 보기’ 표시는 유지합니다.
- 이동 화면의 네 버튼은 기존 18px/52px로 충분히 노출됐습니다. 안내 문장을 짧게 하고 네 장소로의 이동을 실제 조작으로 확인합니다.
- 교실 그래픽·색상·글꼴·퍼즐 규칙·점수·저장 형식은 유지합니다.

## 로컬 검증

- 자동 검사 87개 및 TypeScript·Pages 경로 빌드 통과.
- 목록에서 물건 12개를 모두 선택해 물건 조사와 교실 복귀 확인.
- 단서 카드 5장과 조사한 물건 12개가 있는 노트로 시작·끝·모둠 역할 펼치기를 확인. 568×320에서 긴 노트 끝과 역할 펼친 끝에도 닫기 버튼 노출, 가로 넘침 없음.
- 네 장소 버튼을 눌러 칠판 앞·창가·교실 뒤편·교실 가운데로 이동하고 대화상자가 닫히는 것을 확인.

검증은 브라우저의 가로 화면 에뮬레이션이며 실기기 터치·노치·주소창·모바일 운영체제 전체화면은 제외합니다. 공개 배포 결과는 Actions 및 별도의 화면 기록을 확인합니다.
