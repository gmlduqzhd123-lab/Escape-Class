# 세 에피소드 탐색 지도 점검 · 1.5.1

기존 색상·글꼴·버튼 크기·지도 배치는 유지했습니다. 실기기 검증은 제외합니다.

## 수정 내용

- 이미 살펴본 물건이 다음 목표일 때 `★ 다음 물건 · ✓ 살펴봄`을 함께 표시합니다. 쪽지를 찾은 뒤 게시판으로 돌아갈 때, 살펴본 도구함이 다음 목표가 될 때 방문 표시가 사라지던 문제를 수정했습니다.
- 지도 그림의 물건 설명과 아래 선택 버튼이 같은 목표·방문 상태를 사용합니다. 목적지를 지나가기만 해서는 방문 표시를 붙이지 않고, 물건 조사 화면을 열었을 때 표시합니다.
- 일반 이동 중 각 통로에 도달할 때 실제 위치 이름과 저장 위치를 즉시 갱신합니다. 지도를 열거나 일시정지해 이동이 중단되면 마지막으로 도달한 안전한 통로를 표시하고, 이어하기에서도 같은 위치를 복원합니다.
- 기존 진행 저장 형식·점수·퍼즐 규칙을 유지합니다.

## 로컬 브라우저 검증

- 568×320 가로 화면에서 교실·도서관·체육관의 물건 12개씩을 탐색 지도에서 직접 선택했습니다. 물건 조사 후 실제 공간의 장소 이름·지도 위치 이름·표시점 좌표를 비교했습니다.
- 새 게임에서는 방문 표시가 없고 게시판만 다음 목표입니다. 게시판 조사→쪽지 발견→메모 해결에 따라 다음 목표가 쪽지→게시판→도구함으로 바뀌고, 이미 조사한 물건의 방문 표시가 유지되는 것을 확인했습니다.
- 세 에피소드 모두 창가·뒤편에서 저장→시작 화면→새로고침→이어하기 후 현재 위치·다음 목표·방문한 12개 물건을 확인했습니다.
- 체육관에서는 움직임 줄이기를 끈 상태로 뒤편에서 창가로 이동했습니다. 중간 통로에 도착한 뒤 지도를 열어 이동을 중단하고, 지도와 실제 장소가 일치하는 것과 저장·새로고침·이어하기 복원을 확인했습니다.
- 지도 목록의 가로 넘침과 버튼 내부 글자 잘림이 없고, 목록을 스크롤해 물건을 선택할 수 있음을 확인했습니다.

단위·회귀 검사는 `npm test`, Pages 경로 빌드는 `PAGES_BASE=/Escape-Class/ npm run build`, 오프라인 파일 검사는 `npm run test:offline`, 용량 검사는 `npm run measure`로 수행합니다. 공개 배포의 워크플로·자산 해시·세 에피소드 재검증 결과는 별도 증거 폴더에 저장합니다. 브라우저 가로 화면 검증을 실기기 터치·주소창·노치·모바일 운영체제 검증으로 간주하지 않습니다.
