# 가로 화면 알림·스크롤 가림 수정 1.4.8

기존 배포판의 568×320 가로 화면에서 암호를 틀리면 고정 알림이 입력한 숫자를 덮었습니다. 대화상자 밖의 알림은 네이티브 dialog의 최상위 레이어 뒤에 숨을 수 있었습니다.

## 변경

- 스마트폰 가로 화면의 퍼즐 안내는 고정 제목줄 안에서 줄바꿈해 표시합니다. 입력 숫자 위의 떠 있는 알림을 제거했습니다.
- 협동 암호 결과는 키패드 옆 단서 안내 자리에서 표시합니다. 다른 대화상자도 내부에 결과 안내 자리를 둡니다.
- 제목이 줄바꿈되거나 알림·전체화면·화면 크기 변경으로 높이가 달라지면 실제 제목줄 높이를 측정해 스크롤 여백을 갱신합니다. 제목줄 여백과 버튼 여백이 중복되던 부분을 줄였습니다.
- 알림이 나타나고 사라질 때 자동 스크롤 보정으로 읽던 위치가 움직이지 않도록 했습니다. 관찰자는 화면을 다시 그릴 때 해제합니다.
- 색상, 글꼴, 교실 그래픽, 퍼즐 규칙, 점수와 저장 형식은 유지합니다.

## 로컬 검증

- 기존 자동 검사 87개, TypeScript 및 실제 Pages 경로 빌드 통과.
- 브라우저의 568×320 가로 화면으로 새 게임부터 협동 암호, 다섯 필수 퍼즐, 조각 조합, 화분, 열쇠 사용을 거쳐 80점 탈출 완료. 콘솔 오류 없음.
- 오답 안내와 입력 숫자가 겹치지 않음. 긴 단서 노트 끝에서도 제목과 48×48 닫기 버튼 노출. 노트 가로 넘침 없음.
- 알림이 있는 퍼즐 제목줄 높이 109px에 따라 스크롤 여백이 117px로 갱신됨. 노트 제목줄 56px에 대한 여백 78px 적용.
- 667×375로 변경한 뒤에도 진행 상태와 탈출 동작 유지.

실기기와 모바일 브라우저의 주소창·노치·운영체제 전체화면은 이번 검증에서 제외합니다. 전체화면 상태 전이는 자동 검사와 데스크톱 브라우저 조작으로 확인하며, 모바일 네이티브 동작 통과로 간주하지 않습니다.
