# EP.02 스마트폰 가로 화면 점검 1.4.14

## 확인과 수정

- 배포된 EP.02를 스스로·25분·협동 단서 설정으로 새 게임부터 필수 다섯 퍼즐, 책갈피 조합, 화분의 열쇠, 출구, 80점 결과까지 직접 조작했습니다.
- 도서관에서 저장 후 시작 화면으로 돌아오면 EP.01 제목이 표시되어 다른 활동을 이어가는 것처럼 보였습니다. 저장한 에피소드에 맞게 시작 화면과 브라우저 제목을 표시하고, 이어하기 버튼에 EP.02·도서관을 명시했습니다. 새 게임 설정 화면은 두 에피소드 선택을 유지합니다.
- 책 전달 길의 ‘골대’를 ‘도착점’으로 바꾸고, 도움 지도의 시작 장소와 실시간 도착 안내를 ‘도서관’으로 맞췄습니다. 내부 이동 값 ‘교실’과 기존 진행 기록은 유지합니다.
- 화면을 다시 그릴 때와 실시간 안내가 같은 에피소드 표현을 사용합니다. 원문을 저장하고 화면에 표시할 때 한 번만 변환하여 물건 이름이 중복 변환되지 않게 했습니다.
- 568×320에서 길 완성 후 ‘책 전달하기’ 버튼이 y=330~378로 화면 밖에 있었습니다. 가로 화면에서는 도착점에 닿으면 진행 버튼이 보이는 위치로 이동합니다. 확인한 수정 후 위치는 y=157~205입니다. 친구 방문 여부와 경로의 정답 판정은 그대로 유지합니다.
- 색상·글꼴·교실 및 도서관 장면·퍼즐·점수·기존 저장 키와 공식 결과 제한은 유지합니다.

## 로컬 검증

- 단위·회귀 검사 92개 통과. 저장된 에피소드의 이어하기 표시, 도서관 장소 표시와 기존 이동 값 보존, 에피소드별 안내 변환 검사 포함.
- TypeScript 검사 및 Pages 경로 프로덕션 빌드 통과.
- 568×320에서 긴 EP.02 제목과 새 게임·이어하기 버튼이 첫 화면에 표시됩니다. 이어하기 버튼은 y=166~236이며 가로 넘침이 없습니다.
- 메모 한 장 및 협동 암호 `6__` 저장→시작 화면→새로고침→EP.02 이어하기 확인. 협동 단서를 다시 읽지 않고 남은 암호 입력 가능.
- 568×320에서 책 전달 길과 진행 버튼, 667×375에서 단서 노트·도움 지도·책갈피 조합, 844×390에서 열쇠·출구·결과까지 플레이했습니다.
- 도서관 복귀 시 화면과 실시간 안내에 ‘도서관에 도착했어요.’ 표시. 내부 이동 값은 ‘교실’ 유지.
- 책갈피 두 조각을 놓은 상태로 새로고침하고 전체화면으로 이어하기: 조각과 스크롤 위치 318px 유지. 남은 세 조각을 놓아 80점 탈출.
- 단서 노트 끝까지 스크롤한 상태에서 고정 닫기 버튼 48px 노출. 결과 카드 자동 이동, 하단 두 버튼 52px 노출, 완료 기록 이어하기 시 결과 맨 위 표시.
- 확인한 로컬 브라우저 오류 로그 없음.

브라우저 뷰포트와 데스크톱 전체화면에서 확인했습니다. 실기기 터치, 모바일 주소창·노치·운영체제 전체화면 검증은 사용자 요청에 따라 제외합니다. Pages 배포 후 공개 주소 플레이, Actions 상태, 자산 해시는 별도 기록합니다.
