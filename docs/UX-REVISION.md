# 1.1 방탈출 조작 개선

2026-10-23. 기존 교실 일러스트·동물 캐릭터·글꼴·세이지/크림/나무 색상과 시작·결과 화면의 스타일을 유지했습니다. 장치의 조작과 탐색 화면 구성을 변경했습니다.

## 바뀐 진행

교실에서 물건 선택 → 장치 확대 → 단서·도구 조작 → 장치 반응과 조각 발견 → 다음 단서 안내 → 교실 탐색으로 이어집니다.

- 현재 목표 한 가지와 맥락에 맞는 힌트를 표시합니다. 물건 목록은 필요할 때만 엽니다.
- 아래 아이템 칸에서 도구를 고른 뒤 대상 물건이나 암호판을 눌러 사용합니다. 틀린 대상에 사용해도 도구는 남습니다.
- 메모는 선택 후 홈에 놓으며, 렌즈와 놓인 최종 조각은 직접 눌러 돌립니다.
- 공은 이웃 칸을 차례로 눌러 길을 만듭니다. 한 칸 취소·초기화 후 다시 시도할 수 있습니다. 기존 공 시뮬레이션으로 네 친구와 골대 도착을 판정합니다.
- 사진 전달망과 도움 요청망은 그림 속 선을 눌러 조작합니다. 도움 지도에서는 장소를 고른 뒤 해당 어른에게 전할 말을 고릅니다.
- 필수 장치가 맞으면 자동으로 조각과 다음 단서를 안내합니다. 추가 단서는 별도 탭에서 살펴봅니다.
- 학생 화면의 내부 코드 대신 물건·단서·조각의 이름을 표시합니다.
- 긴 장치는 내부 스크롤과 안내 표시를 제공하며 버튼을 눌러도 스크롤 위치를 유지합니다. 모든 조작은 클릭과 키보드로 가능합니다.

## 저장과 운영

콘텐츠·점수·공식 결과 형식을 유지했습니다. 이전 공 퍼즐의 화살표 전용 저장은 이동 경로를 복원해 새 방식으로 표시합니다. 잠긴 장치 조작, 잘못된 경로와 저장 필드는 계속 거부합니다.

실제 학교 목록·공식 회차·공개 순위는 변경하지 않았습니다. 이름·학생 계정·외부 DB·결과 전송 기능을 추가하지 않았습니다. GitHub Actions에서도 핵심 검사 후 빌드·Pages 배포를 수행합니다.

## 로컬 검증

- TypeScript/Vite 빌드 성공.
- 핵심 로직 35개 통과. 공 경로 조작·과거 저장 이관·맥락별 목표와 힌트 검사를 포함합니다.
- 설치된 Edge의 Playwright 검사 27개 통과, 런타임 오류 0.
- PC에서는 실제 키보드로 전 과정과 추가 단서 네 개를 해결해 100점 탈출. 기본 공 애니메이션을 사용했습니다.
- 360px 화면에서는 클릭으로 전체 과정과 추가 단서 두 개를 해결해 90점 탈출. 공식 회차·학교는 브라우저 응답만 가상 fixture로 대체해 다운로드 필드와 회차 변경·종료 차단을 확인했습니다.
- 360/768/1440px 화면의 가로 넘침, 44px 버튼, 계속 보이는 아이템 칸, 내부 코드 비노출, 장치 스크롤 유지, Escape·초점 복귀, 일시정지·이어하기를 검사했습니다.
- 저장 차단·데이터 누락·필수 자산 실패와 재시도·로컬 집계·다른 앱 저장 보존을 확인했습니다.

검사 재현 방법은 README에 있습니다. 현재 실행 결과는 `EVIDENCE_DIR`에 기록됩니다. 저장소의 기존 `evidence/`와 `docs/COMPLETION.md`는 최초 구현 당시 기록으로 보존했습니다. 배포 성공과 공개 사이트 재검증은 실제 Actions 실행 및 공개 주소에서 별도로 확인해야 합니다.

실제 학생·교사 수업이나 물리 태블릿의 사용성 검증은 수행하지 않았으며, 화면 크기는 브라우저에서 재현했습니다.
