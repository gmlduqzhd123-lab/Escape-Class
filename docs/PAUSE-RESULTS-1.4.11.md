# 일시정지·설정·결과 가로 화면 개선 1.4.11

## 확인한 문제와 수정

- 결과 기록의 항목명이 13px이고 되돌아보기 버튼은 16px/46px 높이였습니다. 가로 화면에서 항목명 16px, 내용 18px, 버튼 18px/52px 이상으로 맞췄습니다.
- 실천 문장을 고르면 카드가 화면 아래에 남았습니다. 가로 화면에서 선택한 카드 영역으로 초점과 스크롤을 이동해 바로 확인하게 했습니다.
- 결과 화면의 장식·여백을 줄이고 기록은 두 열로 정리했습니다. 결과 보관 버튼과 시작·새 게임 버튼을 각각 독립된 묶음으로 배치했습니다.
- 일시정지 버튼과 설정 선택 행도 18px/52px 이상으로 맞추고 설정 설명을 짧게 다듬었습니다.
- 색상·글꼴·그림·점수·게임 규칙·저장 형식·공식 결과 다운로드 제한을 유지합니다.

## 로컬 검증

- 자동 검사 87개 및 TypeScript·Pages 경로 빌드 통과.
- 568×320, 667×375, 844×390에서 일시정지 버튼과 설정 두 행 노출, 가로 넘침 없음.
- 일시정지 중 표시 시간 04:21 유지, 저장하고 시작 화면으로 이동한 뒤 이어하기로 16점 진행 복원.
- 효과음·움직임 줄이기 선택·해제 후 게임 진행 확인. 기존 진행에서 실제 퍼즐을 풀어 80점 탈출.
- 세 크기에서 실천 카드 선택 후 카드 전체와 ‘선택한 실천 카드’ 초점 노출. 568×320의 카드 영역은 y=16~159.
- 하단 시작·새 게임과 결과 보관 버튼의 52px 높이 확인. 현재 설정 새로 확인 후 80점 유지.

실기기 터치·주소창·노치·모바일 운영체제 전체화면은 제외합니다. 인쇄 창을 실제로 출력하거나 공식 결과 제한을 우회하는 검증은 하지 않습니다. 공개 배포 결과는 Actions와 별도 화면 기록을 확인합니다.
