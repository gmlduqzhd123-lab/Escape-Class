# 1.2 화면 기반 사용성 검토와 단순화

2026-10-23. 배포된 1.1 게임을 새로 시작해 필수 장치 다섯 개와 추가 단서 네 개를 모두 풀고 100점 탈출까지 진행했습니다. 화면에서 보이는 문구와 버튼을 기준으로 초등학생이 헷갈릴 수 있는 부분을 검토했습니다. 성인 에이전트의 관점 검토이며 실제 학생 관찰이나 수업 검증은 아닙니다.

| 관찰한 어려움                             | 변경                                                         |
| ----------------------------------------- | ------------------------------------------------------------ |
| 메모 뒤집기 → 선택 → 별도 홈 지정         | 내용과 기호를 같이 표시, 한 번 누르면 다음 빈칸에 놓기       |
| 잘못 놓은 메모를 빼도 선택 상태가 남음    | 놓인 메모를 누르면 바로 빼기, 지속적인 상태 안내             |
| 렌즈가 없는데 다음 단서는 암호판으로 이동 | 먼저 렌즈를 구하는 곳으로 안내, 획득 뒤 암호판 직행 버튼     |
| 렌즈 회전과 사용 대상이 모호함            | 명시적인 올리기·돌리기 버튼, 읽은 세 창을 입력부에 함께 표시 |
| 긴 장치 내부에 다음 행동이 숨음           | 중첩 스크롤 제거, 페이지 스크롤과 하단 교실 복귀 버튼        |
| 공의 지나온 칸을 눌러도 길을 고칠 수 없음 | 지나온 칸은 그곳까지 되돌리기, 이웃이 아닌 새 칸은 비활성화  |
| 어른에게 도착해도 대화가 지도 아래 숨음   | 대화를 먼저 표시하고 해당 위치로 이동                        |
| 도움 문장의 순서가 다르면 무반응          | 먼저 도움 요청 → 편한 대화 방법 중 하나 선택                 |
| 마지막 조각 배치와 반복 회전              | 한 번 누르면 빈칸에 반듯하게 맞춤, 순서를 틀리면 눌러 빼기   |
| 열쇠 발견 뒤 다시 선택하고 출구 찾기      | 열쇠 발견 화면에서 출구 열기 버튼                            |
| 추가 단서가 필수 미완료처럼 표시됨        | 선택 활동임을 명시하고 성공 버튼을 우선 표시                 |
| 숫자 자물쇠의 기호와 범례가 어긋남        | 같은 SVG 기호·한글 이름 사용, 숫자 버튼으로 입력             |

교실 일러스트·동물·기존 글꼴·색상·원본 기본 CSS를 유지했습니다. 점수, 결과 파일 형식, 개인 정보 입력 금지, 학교·회차·순위 데이터와 정적 운영 구조도 유지합니다. 이전에 놓은 조각은 조합판을 다시 열 때 순서를 보존하면서 반듯하게 맞춥니다.

핵심 검사는 직접 배치의 발견·선행 조건, 수정과 중복 방지, 길 되돌리기, 이전 저장 복원, 두 어른·두 대화 선택, 일시정지·탈출 후 변경 차단을 포함합니다. 기존 화살표 저장 이관 및 결과·순위·파일 검증 검사도 유지합니다.

이번 검증은 빌드·핵심 검사 후 허용된 공개 HTTPS 주소에서 다시 플레이하는 방식으로 진행합니다. 로컬의 연결 실패 탭은 브라우저 보안 정책에서 접근을 거부하여 로컬 화면 검증에는 사용하지 않습니다. 현재 배포·화면 검증 결과는 이 작업의 별도 출력 보고서에 기록하며, 기존 1.1 보고와 스크린샷을 덮어쓰지 않습니다.
