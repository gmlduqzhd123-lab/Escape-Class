# 시작·준비·이야기 안내 가로 화면 개선 1.4.12

## 확인한 문제와 변경

- 568×320 배포판의 새 게임·이어하기 버튼이 y=510~568에 있어 첫 화면에서 보이지 않았습니다. 가로 화면에서는 기존 제목 옆에 두 버튼을 배치하고 상단 메뉴 높이를 줄였습니다. 제목·색상·글꼴·교실 그림은 유지합니다.
- 준비 화면의 중복된 ‘학교 없이 시작’ 설명을 합쳤습니다. 등록 학교가 있으면 기존 검색·학교 선택·소속 인증 안내를 그대로 표시합니다.
- 준비 화면의 선택 행과 수업 설정 버튼을 18px/52px 이상으로 맞췄습니다. 진행 버튼은 가로 화면의 전체 폭을 사용합니다.
- 이야기 안내의 문장과 장식 여백을 다듬고 안전 안내·세 가지 조작·타이머·전체화면 나가기·모둠 역할을 유지했습니다. 넓은 가로 화면에서는 세 조작을 나란히 읽습니다.
- 짧아진 문장도 EP.02의 도서관 이야기로 바뀌도록 기존 변환 목록을 보완했습니다.
- 퍼즐·점수·저장 형식·학교 선택 제한·설정 값은 유지합니다.

## 로컬 검증

- 기존 검사와 학교 등록 유무별 준비 화면 회귀 검사를 포함해 88개 통과. 등록 학교가 있을 때 검색·선택·학교 없이 체험·선택한 학교 표시 유지.
- 568×320 첫 화면의 새 게임 버튼 y=109~161, 이어하기 y=169~221로 두 버튼 모두 표시.
- 568×320, 667×375, 844×390에서 준비·이야기 안내의 마지막 버튼과 새 게임 확인·취소 노출, 가로 넘침 없음.
- 차근차근·15분·EP.02를 선택해 안내와 실제 3D 도서관 진입 확인. 게임 시작 전에는 타이머·3D 장면이 없고, 시작 후 3D 장면과 시간이 표시됨.
- 시작 후 일시정지·저장·시작 화면 복귀·새 게임 확인 취소 동작 확인.

실기기 터치·주소창·노치·모바일 운영체제 전체화면 검증은 제외합니다. 공개 배포 결과는 Actions와 별도 화면 기록을 확인합니다.
