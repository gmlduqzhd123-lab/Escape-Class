# 스마트폰 가로 최종 플레이 점검 1.4.13

## 개선

- 기존 배포본을 568×320에서 새 게임부터 필수 퍼즐 다섯 개, 조합판, 화분의 열쇠, 출구, 80점 결과까지 직접 조작했습니다. 메모·렌즈 암호·길 찾기의 부분 진행도 저장 후 새로고침과 이어하기로 확인했습니다.
- 퍼즐 내용은 복원되지만 긴 장치 화면은 맨 위에서 다시 찾아 내려가야 했습니다. 장치의 스크롤 위치를 기존 경험 기록의 선택 필드로 함께 저장하고, 이어하기와 전체화면 진입 완료 후 복원합니다. 다른 화면 크기에서는 현재 스크롤 범위로 제한됩니다.
- 가로 화면의 장치 고정 줄에 48px 이상의 일시정지 버튼을 넣었습니다. 장치 아래에서도 쉬거나 저장할 수 있습니다. 기존 상단의 중복 버튼은 이 화면에서만 숨깁니다.
- 일시정지에 이어갈 물건을 표시합니다. EP.02에서는 기존 도서관 이름 변환을 적용합니다.
- 필수/선택 장치를 바꿀 때 이전 장치의 스크롤을 물려받지 않고 새 설명부터 보여 줍니다. 같은 장치에서 조작하거나 대화상자를 닫을 때는 기존 위치를 유지합니다.
- 색상·글꼴·교실 그림·퍼즐·점수·진행 저장 키는 유지합니다. 구형 기록의 스크롤 필드 누락 및 잘못된 값은 0으로 복구하여 나머지 기록을 보존합니다.

## 로컬 검증

- 단위·회귀 검사 89개 통과. 저장 sidecar와 본 진행의 일치, 위치 추가 후 구형/잘못된 위치 복원 검사 포함.
- Pages 경로로 TypeScript 검사 및 프로덕션 빌드 통과.
- 568×320 새 게임→메모 중간 저장·재접속→협동 도구함→렌즈→길 찾기 중간 저장·재접속→667×375 태블릿·도움 지도→844×390 조합판·열쇠·탈출 결과까지 직접 조작.
- 길 찾기의 일시정지 직전/이어하기 후 위치 245px 유지. 경로 [10,5,0,1,2,7,12]에서 남은 길을 이어 완성.
- 선택 자물쇠↔필수 우정 조각 전환 후 스크롤 0. 결과 실천 카드 선택 후 카드로 이동. 하단 시작/새 게임 버튼 모두 52px, 가로 넘침 없음. 완료 기록 이어하기는 결과 화면으로 이동.
- 확인한 로컬 브라우저 오류 로그 없음.

브라우저의 가로 뷰포트와 데스크톱 전체화면으로 검증했습니다. 실기기 터치, 모바일 주소창·노치·운영체제 전체화면은 제외합니다. 배포 검증은 별도 공개 주소 기록 및 Actions/HTTP 자산 해시 기록으로 남깁니다.
