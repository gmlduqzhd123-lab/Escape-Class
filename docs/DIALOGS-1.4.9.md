# 가방·도움·메뉴 가로 화면 개선 1.4.9

## 확인한 문제

- 568×320에서 2·3단계 힌트를 열면 새 글의 아랫부분이 화면 밖에 남았습니다. 마지막 단계에서는 없어진 버튼 대신 닫기 버튼으로 초점이 이동했습니다.
- 짧은 가로 화면의 가방·메뉴 버튼에는 이전 스타일의 16px 글자와 48px 높이가 적용됐습니다.
- 메뉴 하위 화면을 닫을 때 하위 화면에 있던 버튼을 찾다가 원래 메뉴 버튼으로 초점을 돌려주지 못했습니다.

## 변경

- 새 힌트 영역에 초점을 주고 자동으로 스크롤합니다. 제목줄 여백을 지켜 새 글을 읽을 수 있습니다. 기존 단계도 스크롤로 다시 읽을 수 있습니다.
- 서로 다른 대화상자를 열 때는 맨 위부터 시작하고, 같은 화면의 갱신에서는 기존 위치를 유지합니다.
- 하위 화면에서도 최초 메뉴를 연 버튼을 기억해 닫은 뒤 초점을 돌려줍니다.
- 스크롤한 이전 글이 제목줄 위 여백으로 비치지 않도록 고정 제목 배경을 여백까지 확장했습니다.
- 가방·메뉴 버튼을 18px, 높이 52px 이상으로 조정하고, 물건 목록의 보조 글씨는 16px로 확대했습니다. 가방 안내 문장은 짧게 다듬었습니다.
- 색상, 글꼴, 교실 그래픽, 규칙, 점수, 저장 형식은 유지했습니다.

## 로컬 확인

- 자동 검사 87개와 TypeScript·Pages 경로 빌드 통과.
- 실제 조작으로 첫 퍼즐과 협동 도구함을 풀고 렌즈 획득. 가방 선택·해제로 게임에 돌아오는 동작 확인.
- 568×320에서 힌트 1~3단계의 새 글, 제목과 닫기 노출 확인. 2단계 글 영역 y=120~236, 3단계 y=120~237로 화면 안에 표시.
- 긴 물건 목록 끝에서도 닫기 버튼 노출, 하위 목록을 닫으면 메뉴 버튼으로 초점 복귀.

실기기 터치·주소창·노치·모바일 운영체제 전체화면 검증은 제외합니다. 공개 배포 검증은 해당 릴리스의 Actions 결과와 별도 화면 기록을 확인합니다.
